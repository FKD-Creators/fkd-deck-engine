# fkd-deck-engine

Engine das apresentações HTML da FKD Creators (sistema visual, navegação, gráficos, símbolos da marca e fontes)
e o player para apresentar um deck. Usado pela skill `apresentacao-fkd` no Gemini e no Claude.
Instruções de uso em `LEIA-ME.md`.

- Engine (jsDelivr): `https://cdn.jsdelivr.net/gh/FKD-Creators/fkd-deck-engine@main/engine/` —
  um deck precisa só de `<script src="https://cdn.jsdelivr.net/gh/FKD-Creators/fkd-deck-engine@main/engine/fkd-boot.js"></script>` no `<head>`.
- Player (GitHub Pages): https://fkd-creators.github.io/fkd-deck-engine/apresentar.html
- Deck de exemplo: https://fkd-creators.github.io/fkd-deck-engine/
