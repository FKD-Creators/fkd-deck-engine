FKD Deck · apresentar

Cole o código do deck ou abra o arquivo

Este é o jeito de apresentar, baixar e gerar o PDF de um deck feito pelo Gemini com a skill apresentacao-fkd, sem instalar nada.

  1. No Gemini, com o deck aberto no Canvas, clique em Code (canto superior direito) e copie o código inteiro. Ou, dentro do preview, use o botão Abrir em nova aba, que já traz o deck para cá.
  2. Cole na caixa abaixo (ou arraste o arquivo index.html para ela).
  3. Clique em Apresentar. Setas avançam; F tela cheia; N notas; C verificação.
Aguardando o código…
Setas ou clique avançam · F tela cheia · N notas · C verificação · B tela preta · Para salvar em PDF, use o botão PDF e depois Ctrl/Cmd+P → "Salvar como PDF", margens "Nenhuma".
